# Agent Instructions

This folder is the source of truth for the VIO website.

## Work Here

Use this folder as the project root for development, design changes, builds, and deployment setup.

- Pages: `src/pages/`
- Components: `src/components/`
- Styles: `src/styles/`
- Static assets: `public/`
- Build output: `dist/`
- Documentation: `docs/`

## Commands

Run commands from this folder.

```sh
npm install
npm run dev
npm run build
```

## Deployment

Publish `dist/`. Do not publish or edit the legacy static files in the parent folder for future site changes.
