## 驗證方式

- 本機瀏覽器實際操作；桌面 1440 × 900、手機 390 × 844。
- 原版：`http://127.0.0.1:4320/index.html`、`index-en.html`、`contact.html`。
- 開發版：`http://localhost:4321/`、`/en/`、`/contact/`。
- 成品：執行 `npm run build`，再於 `http://localhost:4322` 檢查 dist/。
- 比對可見畫面及主要內容元素的文字、尺寸、位置、字型、字級、行高、顏色與顯示狀態。影片時間點與進場動畫不作逐像素一致判定。
